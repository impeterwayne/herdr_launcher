# OpenSpec Agent Guidelines

1. **Explore Before Proposing**: Analyze existing code and specs before proposing modifications.
2. **Atomic Change Proposals**: Put each feature or fix proposal in `openspec/changes/<change-id>/`.
3. **Verify Against Specs**: Run validation and tests to ensure implementation adheres to the proposal.
4. **Archive on Completion**: Move verified change proposals into `openspec/specs/`.
