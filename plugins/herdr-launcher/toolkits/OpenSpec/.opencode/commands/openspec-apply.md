# OpenCode Command: /openspec-apply

Implement the changes defined in an OpenSpec change proposal.


# OpenSpec Apply Skill

Use this skill to apply and execute the tasks outlined in an active change proposal in `openspec/changes/<change-id>/`.

## Workflow
1. Read `openspec/changes/<change-id>/proposal.md`.
2. Incrementally implement each task.
3. Update task checkboxes in `proposal.md` as items are completed.
4. Maintain code formatting and project consistency.
