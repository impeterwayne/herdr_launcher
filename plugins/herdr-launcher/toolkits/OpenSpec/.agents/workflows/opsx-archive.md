# OpenSpec Archive Skill

Use this skill once all tasks in an OpenSpec change proposal are implemented and verified.

## Workflow
1. Consolidate new or updated specifications into `openspec/specs/<domain>/`.
2. Move or archive `openspec/changes/<change-id>/` to `openspec/archive/<change-id>/`.
3. Update `openspec/project.md` to reflect the new state.
