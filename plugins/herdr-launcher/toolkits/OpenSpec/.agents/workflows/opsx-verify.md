# OpenSpec Verify Skill

Use this skill to validate that the implementation satisfies the requirements and passes tests.

## Workflow
1. Read the Verification Plan in `openspec/changes/<change-id>/proposal.md`.
2. Run test suites, linters, and type checkers.
3. Perform end-to-end or manual checks where applicable.
4. Document test results in the verification section.
