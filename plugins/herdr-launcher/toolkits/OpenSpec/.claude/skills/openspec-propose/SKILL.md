# OpenSpec Propose Skill

Use this skill to create or update an OpenSpec change proposal under `openspec/changes/<change-id>/`.

## Workflow
1. Define a concise `<change-id>` (e.g. `add-auth-flow`).
2. Create `openspec/changes/<change-id>/proposal.md` using `openspec/templates/proposal.md`.
3. Outline the motivation, required file changes, step-by-step tasks, and verification criteria.
4. Review the proposal against project constraints before implementation.
